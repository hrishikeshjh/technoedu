HOW TO USE THIS FILE
--------------------
Every examination entry lists:
  [DOC]  official documentation gateway - notifications, eligibility criteria,
         exam pattern, syllabus and roadmap (mostly the official portal; where a
         separate dedicated syllabus/PYQ page exists, it is listed separately).
  [PYQ]  official previous year question papers / sample papers.
  [OER]  free & open-licensed study material (government, university or
         non-profit repositories - no login, no paywall, no purchase).

General Open Educational Repositories used across all sections
  NCERT textbooks (Class 6-12)      : https://ncert.nic.in/textbook.php
  e-Pathshala / DIKSHA              : https://epathshala.nic.in , https://diksha.gov.in
  NPTEL (IIT courseware)            : https://nptel.ac.in
  SWAYAM (Govt MOOCs)               : https://swayam.gov.in
  MIT OpenCourseWare                : https://ocw.mit.edu
  OpenStax (peer-reviewed books)    : https://openstax.org
  Khan Academy                      : https://www.khanacademy.org
  e-GyanKosh (IGNOU repository)     : https://egyankosh.ac.in
  NDLI (National Digital Library)   : https://ndl.iitkgp.ac.in
  e-PG Pathshala (UGC INFLIBNET)    : https://epgp.inflibnet.ac.in
  Project Gutenberg                 : https://www.gutenberg.org
  Internet Archive / Open Library   : https://openlibrary.org
  LibreTexts                        : https://libretexts.org
  Indian Kanoon (legal judgments)   : https://indiankanoon.org
